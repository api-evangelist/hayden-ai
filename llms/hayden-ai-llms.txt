# Hayden AI

> Hayden AI is a San Francisco based artificial intelligence and spatial analytics company. It mounts a purpose-built AI camera and edge compute box on transit buses and other municipal fleet vehicles and uses computer vision to detect bus lane, bus stop, bike lane, double parking and tram blocking violations in real time, for review by authorized transit agencies in the Hayden AI Data Portal.

## API surface

Hayden AI publishes **no public API**. As of 2026-08-04 there is no developer portal, no API reference, no OpenAPI/AsyncAPI/GraphQL contract, no SDK, no MCP server and no A2A agent card. The Data Portal is a customer-only application delivered under contract to transit agencies and municipalities, and it hands verified violation evidence to an agency's existing violations processing system through private integration rather than a documented public API.
